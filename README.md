# Docker for Developers

This is the repository for the LinkedIn Learning course Docker for Developers. The full course is available from [LinkedIn Learning][lil-course-url].

Discover how to leverage Docker for application development. Instructor Emmanuel Henri—an executive and full-stack developer with 20 years of experience in programming, technology, and design—walks you through deploying your first Docker app, from base application setup to deploying your app to the cloud.

Learning objectives

- Analyze the value and benefits of using Docker for setting up development environments.
- Define the fundamental components of Docker, including containers, images, volumes, and networking.
- Demonstrate how to install Docker and set up Docker Desktop on various operating systems.
- Create and configure Dockerfiles to build and run Docker containers.
- Organize and leverage Docker Compose to manage multiple containers in a development environment.
- Develop and run backend and frontend applications using Docker containers.
- Evaluate and utilize Docker Swarm for clustering, scheduling, and managing multiple containers.
- Deploy and manage services to Docker Swarm for scalable application deployment.
- Construct and manage Kubernetes clusters for deploying, scaling, and running applications.
- Apply continuous integration practices using Travis CI and Docker for automated testing and deployment.
